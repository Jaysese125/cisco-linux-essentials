### Before You Get Started

#### Before You Get Started
- **1. Course Overview & Certification Goals**
  - **What I Learned:** This course acts as the entry point for Linux CLI skills and directly aligns with the **LPI Linux Essentials (010-160)** exam.
  - **Core Takeaways:** 
    - Linux isn't just an operating system; it's an ecosystem built on FOSS (Free and Open Source Software) principles.
    - Key areas I'll master include command-line mechanics, file management, system security/permissions, archiving, and writing entry-level Bash scripts.

- **2. Interacting With the Course**
  - **Interface Discoveries:**
    - The **Navigation Tabs** split readings (**Content**), exam alignment (**Objectives**), and definitions (**Key Terms**).
    - **Virtual Terminal:** Live Linux CLI embedded directly next to the reading content for real-time command practice.
  - **Critical Environment Note:** The in-browser virtual environment is **ephemeral**. Any custom files created or shell modifications made will be wiped when the session resets.
  - **Credentials Logged:** 
    - Default user session: `sysadmin` (Prompt displays `sysadmin@localhost:~$`).
    - Administrative access: Switch to superuser/root using command `su` with password `netlab123` (Prompt changes to `root@localhost:~#`).

- **3. Getting Certified with LPI**
  - **What I Learned:** The Linux Professional Institute (LPI) offers vendor-neutral certifications that are recognized across system administration, cloud computing, cybersecurity, and DevOps.
  - **Personal Value:** Earning this certificate proves baseline CLI proficiency to potential employers before taking advanced tracks.

- **3.1 Learn More About the LPI Linux Essentials Certification**
  - **Takeaway:** Linux Essentials serves as the foundational prerequisite step before advancing to professional certifications such as **LPIC-1**.
  - **Resource:** Official guidelines and objectives are maintained at [lpi.org](https://www.lpi.org).
