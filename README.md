## 📖 About This Repository

Welcome to my Linux Essentials learning journey. This repository documents my progress, lab notes, and Bash scripts as I prepare for the **LPI Linux Essentials (010-160)** certification via the NDG Linux Essentials course on Cisco NetAcad.

My goal is to demonstrate foundational Linux CLI proficiency, file management, system security, and entry-level Bash scripting to potential employers.

---

## 🎓 Course & Certification Details

- **Course:** NDG Linux Essentials
- **Certification Goal:** LPI Linux Essentials (010-160)
- **Learning Environment:** Cisco NetAcad LMS with embedded virtual terminals.
- **Core Focus Areas:** Command-line mechanics, file management, system security/permissions, archiving, and writing entry-level Bash scripts.

### ⚙️ Course Setup Notes
- **Setup:** Created an NDG account to access external tools and labs.
- **Interface:** Navigation tabs split readings (Content), exam alignment (Objectives), and definitions (Key Terms).
- **Virtual Terminal:** Live Linux CLI embedded directly next to the reading content. *Note: This environment is ephemeral; any custom files or shell modifications are wiped when the session resets.*
- **Lab Access:** Default user session is `sysadmin` (Prompt: `sysadmin@localhost:~$`). Administrative access requires switching to superuser using `su`.
